# 执行计划

## 需求分析

- **目标**：为顶部工具栏的表格图标添加类似 Word/Google Docs 的表格网格选择器交互。点击图标仍默认插入 3×3 表格；hover 时弹出 4×4 卡片，鼠标移动选中相应行列数并高亮，松开/点击时插入对应大小的表格。
- **关键约束**：
  - 使用 VSCode `--vscode-*` CSS 变量适配亮/暗主题
  - 沿用现有 toolbar 的 tooltip + `ToolbarItem` 模式
  - WebView 侧 TypeScript，通过 Milkdown commands 插入表格
  - 不影响 dev 分支并行开发（用 git worktree 或新分支隔离）
- **验收标准**：
  1. 点击表格 icon → 立即插入 3×3 表格（行为不变）
  2. hover 表格 icon → 在 icon 下方弹出 4×4 方格卡片
  3. 鼠标移入卡片 → 高亮当前选中的行×列区域（左上角到鼠标位置的矩形）
  4. 鼠标移出卡片或移向不同位置 → 高亮实时跟随更新
  5. 点击卡片中的某个方格 → 插入对应大小的 Markdown 表格，卡片消失
  6. 鼠标从 icon 移出到卡片区域外（且非卡片本身） → 卡片延迟关闭（~300ms）
  7. 亮/暗主题下视觉正常

## 实现方案

### 步骤 0：创建开发分支

- **目标**：隔离开发，不影响 dev 分支的并行会话
- **具体操作**：`git worktree add ../markdownView-table-grid -b feat/table-grid main` 或在当前仓库新建 `feat/table-grid` 分支
- **涉及文件**：无
- **验证方式**：`git branch` 确认切换正确

### 步骤 1：新增 `webview/components/toolbar/tableGridSelector.ts`

- **目标**：实现表格网格选择器组件
- **具体操作**：
  - 创建 `TableGridSelector` 类，管理一个 4×4 网格 DOM 容器
  - 容器 `<div class="table-grid-selector">` 包含 16 个 `<div class="grid-cell">` 以 CSS Grid 排列
  - 暴露方法：
    - `attachTo(anchor: HTMLElement)`：绑定到表格 icon
    - `show()` / `hide()`：显示/隐藏（hide 时清除选中状态）
    - `onSelect(callback: (rows: number, cols: number) => void)`：选择回调
  - 内部逻辑：
    - `mouseenter` 每个 cell → 计算当前 hover cell 的 `(row, col)` → 从 `(0,0)` 到 `(row,col)` 的矩形全部高亮
    - 所有 cell 添加/移除 `.selected` class
    - click 某个 cell → 触发 `onSelect(row+1, col+1)` 并 hide
    - 鼠标移出整个容器（而非 icon）时，延迟 300ms hide
    - 鼠标从 icon 进入容器时取消延迟 hide
  - **涉及文件**：`webview/components/toolbar/tableGridSelector.ts`（新建）
- **验证方式**：语法检查 + 单元测试（hover 状态机、行列计算、延迟关闭）

### 步骤 2：添加表格网格选择器的 CSS 样式

- **目标**：为网格选择器添加主题适配的视觉样式
- **具体操作**：
  - 在 `webview/style.css` 中（或新建 `webview/components/toolbar/tableGridSelector.css`）添加样式：
    - `.table-grid-selector`：absolute 定位、圆角、阴影、`var(--vscode-editorWidget-background)` 背景、`var(--vscode-editorWidget-border)` 边框
    - `.grid-cell`：固定尺寸（如 18×18px）、内边距、`var(--vscode-editorWidget-background)` 默认背景
    - `.grid-cell.selected`：`var(--vscode-button-background)` 高亮色
    - hover 时 cell 边框可见（`var(--vscode-button-border)`）
  - 使用原生 CSS 嵌套语法（项目允许）
- **涉及文件**：`webview/components/toolbar/tableGridSelector.ts`（内联样式或独立 CSS）或 `webview/style.css`
- **验证方式**：F5 调试实例中目视确认亮/暗主题

### 步骤 3：修改 `webview/components/toolbar/index.ts` 集成网格选择器

- **目标**：将表格网格选择器挂载到现有表格 icon 上，替换/增强默认行为
- **具体操作**：
  - 在 toolbar 初始化时，找到 table action 的 DOM 元素
  - 创建 `TableGridSelector` 实例并 `attachTo` 到该元素
  - 保留原有 click 逻辑（默认插入 3×3），在 `onSelect` 回调中调用已有的 `insertTable` 逻辑，传入动态行数/列数
  - 确保 click 事件不与 hover 触发冲突（click 直接触发默认行为；hover 弹出卡片后，卡片 click 触发自定义尺寸插入）
  - 处理焦点管理：卡片 show 时阻止 editor 失焦，hide 时恢复
- **涉及文件**：`webview/components/toolbar/index.ts`
- **验证方式**：
  1. click icon → 3×3 表格立即插入
  2. hover icon → 卡片弹出
  3. 卡片内 hover → 高亮更新
  4. 卡片内 click → 对应大小表格插入

### 步骤 4：复用/调整 Milkdown insertTable command

- **目标**：确保 insertTable command 支持动态行列参数
- **具体操作**：
  - 检查现有 `insertTable` 调用链（toolbar → insertTable command → Milkdown）
  - 若现有 insertTable 为 `insertTableCommand(ctx)` 且参数固定为 3×3，需传入动态 rows/cols
  - Milkdown 的 `@milkdown/preset-gfm` 提供了 `InsertTable` command，通常接受 `{ row, col }` 参数，确认后直接使用
- **涉及文件**：`webview/components/toolbar/index.ts`（调用处）
- **验证方式**：测试插入 1×1、2×4、4×4 等不同大小的表格，确认生成正确 Markdown

## 风险与对策

| 风险 | 对策 |
|------|------|
| 现有 `InsertTable` command 不支持动态行列参数 | 检查 Milkdown API 文档；若不支持，用 ProseMirror `table` schema 直接创建节点 |
| hover/click 事件冲突：鼠标进入 icon 触发 hover 卡片，但 click 也需保留 | 区分：单击 icon（无延迟）直接插入 3×3；仅 hover 才弹卡片；卡片内 click 才用自定义尺寸 |
| 卡片位置在窗口边缘溢出 | show 时检测视口边界，动态调整定位方向 |
| 焦点丢失导致 editor 命令失败 | 卡片 show 时对 editor view 调用 `requestFocus`，或用 ProseMirror transaction 直接插入而不依赖 focus |
